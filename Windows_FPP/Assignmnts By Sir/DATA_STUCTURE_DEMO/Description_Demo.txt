Description :
'Catch Me If You Can' is a simple 2D game with key controls. 
The Main Purpouse of the demo is to utilize the knowledge of Fixed Function Pipeline.

In this demo I have used the concepts of FFP like PushMatrix(),PopMatrix(),glTranslatef(),
glRotatef(),glScalef(),gluSphere,gluPerspective() and many more which is very important to
thoroughly understand Programmable Pipeline.

Technology Used :
OS:  Windows 10
SDK: Win32
Language: C
Rendering: OpenGL FFP
Music Editing: Audacity
